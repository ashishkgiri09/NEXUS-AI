Nexus — System Architecture

Nexus is an autonomous, cloud-native software engineering platform that transforms high-level natural language feature requests into fully implemented, tested, and verified pull requests. Operating entirely inside isolated ephemeral cloud workspaces, Nexus coordinates a specialized multi-agent hierarchy—spanning PRD creation, architecture planning, multi-agent code generation, headless browser-driven visual/functional testing, and automated code review.

Client-Agnostic Cloud Execution Autonomous Self-Correction Loop Dual Human Approval Gates Multimodal Visual QA

01. Complete End-to-End Workflow

Lifecycle progression from feature prompt to verified Pull Request.

Step 1 — Input

User Request & Repo Link

Developer specifies a natural language prompt and authorizes Git repository access.

Step 2 — Specs

PRD Agent & Gate 1

Elicits user stories & acceptance tests. Developer reviews and approves the PRD in the dashboard.

Step 3 — Blueprint

Architect Agent & Gate 2

Inspects codebase AST and plans target file diffs. Developer approves the technical architecture.

Step 4 — Build & QA

Dev-Test Feedback Loop

Developers code, Tester executes headless Playwright tests & visual QA, self-correcting any bugs.

03. Agent Specifications & Roles

Responsibilities, inputs, outputs, and verification standards for each agent.

Agent Core Role Inputs Outputs Verification Gate
PRD Agent User stories, acceptance criteria, scope boundaries User prompt, README, repo context Structured PRD Markdown Human Approval Gate 1
Architect Agent Codebase AST analysis, file plan, API contracts Approved PRD, file tree, configs Technical Architecture Blueprint Human Approval Gate 2
Developer Agent(s) Code generation, refactoring, unit tests Arch plan, diagnostic error packets Code patches, Git diffs Syntax & Compilation
Tester Agent Runs app, executes tests, captures UI screenshots Workspace build, acceptance tests Logs, traces, visual proof 100% Pass & Vision QA
Reviewer Agent Security audit, code quality, PR publishing Git diff, PRD, test traces Verified GitHub/GitLab PR Ready for Merge

04. Autonomous Self-Correction Sequence

Autonomous error recovery cycle between Developer and Tester agents.
